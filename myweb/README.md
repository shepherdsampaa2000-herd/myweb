# Shepherd Sampa - ICT251 Activity 3

## Project Description
This is my personal portfolio website, which I improved from Activity 2. It shows information about me, my hobbies, learning plan, projects, and media.

## Technologies Used
- HTML
- CSS
- JavaScript

## JavaScript Features
1. Buttons to show and hide project details.
2. Previous and Next buttons to view photos.
3. A button to switch between light and dark themes.
4. A contact form that checks the information entered and displays a preview.

## How to Run the Website
1. Open the project in Visual Studio Code.
2. Open `index.html` using Live Server.
3. Click through the website and test its features.

## Testing
I will test the website on both computers and mobile screens. I will also check that the buttons work and that the contact form accepts valid information and rejects incorrect information.
